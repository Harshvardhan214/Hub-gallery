Welcome to the Animated Menu

Click the menu button in the top-left corner to open the animated navigation menu. Toggle between light and dark modes using the theme button in the top-right corner.

The background features an orthogonal grid pattern that adapts to the current theme. You can also swipe the menu left to close it on mobile!

Features

  • • Staggered entrance animations
  • • Swipe-to-close functionality
  • • Modern CSS Variables for Theming
  • • Smooth Bezier transitions
  • • Responsive layout
  • • Grid background logic
